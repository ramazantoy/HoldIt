## Doğrulananlar (F3, kaynaktan ve Editor'da)
| Konu | Sonuç → kural |
|---|---|
| Button carry-over (`InputActionState.ProcessDefaultInteraction`) | Waiting'de `isButton` ve aktüasyon ≥ eşik → herhangi bir değişimde performed; Button'da initial state check yok (`wantsInitialStateCheck` yalnız Value). Event işlenirken eklenen state monitor o event için sinyal almaz → dijital tuş sızmaz, analog sızar. `CarryOverTests` ilk testi tuzağı kanıtlar; Input System güncellemesinde kırılırsa filtre gözden geçirilir |
| Generated C# class | Constructor `InputActionAsset.FromJson(...)` → ayrı kopya |
| `InputSystemUIInputModule` 1.20 | `OnEnable` referans verdiği action'ları refcount ile açar; referans atama `isActiveAndEnabled` ise de açar (Edit Mode dahil). `OnDisable` yalnız default action'ları siler (1.14'teki "kapatınca action'lar silinir" değişti). Editor'da eklenince `Reset` DefaultInputActions atar |
| InputForUI (UI Toolkit, EventSystem yokken) | Project-wide actions'ın UI map'i, yoksa kendi DefaultInputActions'ı; modları ve rebind'i atlar |
| Binding override | `m_OverridePath/Interactions/Processors` `[NonSerialized]`: domain reload'da gider, asset'i kirletmez |
| `RebindingOperation` 1.20 | Action enabled iken `Start` fırlatmıyor; `PerformInteractiveRebinding` pointer position/delta'yı hariç tutar, 0.05 sn daha iyi eşleşme bekler, eşleşen event'i bastırır. `WithCancelingThrough` tek yol → çoklu iptal `onAnyButtonPress` ile |
| `FindControlSchemeForDevice` | Tek cihazla `PickDevicesFrom` → iki cihaz isteyen Keyboard&Mouse klavyeyle tek başına eşleşmez; bağlı cihazlarla `FindControlSchemeForDevices(..., mustIncludeDevice)` |
| `.inputactions` alt asset'leri | Her action için iki `InputActionReference`: görünür (file id action id'sinden) ve gizli eski uyumluluk kopyası (file id isimden) |
| Test framework | `Unity.InputSystem.TestFramework` derleniyor (`UNITY_TESTS_FRAMEWORK`); `InputTestFixture.runtime` internal → `AddDevice` cihazları native değil |
| Play (Editor, kare adımlama) | Menu'de yalnız Controls/UI açık, DefaultInputActions yok; pause → `menu`, Gameplay kapalı; resume → `gameplay`; `Gameplay/Pause` override'ı quit'te `global.json`'a yazıldı, sonraki Play'de geri geldi |
| `InputSystem.onEvent` / `onAnyButtonPress` | `InputManager.OnUpdate`'te dinleyiciler event'in state'i yazılmadan önce çalışır (`:3490` → `ProcessEvent` `:3512`). Orada map açan kod basılı tuşu "bırakılmış" görür; işi `onAfterUpdate`'e ertele |
| Binding değişikliği (1.20) | Override ekleme/silme `OnBindingModified` → full resolve, asset'in **tüm** map'leri (paylaşılan state). Açık map'lerin action'ları geçici kapatılıp action bazında geri açılır: açık/kapalı durumu korunur, kapalı map dirilmez. Süren action'lar iptal edilir (`canceled` gelir), held Button yeni basış bekler. Rebind ekranının action dirilten "snapshot → `asset.Disable()` → geri aç" kodu Input System'in değil, oyunun kendi kodu olurdu |
